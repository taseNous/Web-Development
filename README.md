# Web-Development
This project is a volunteer coordination platform designed to facilitate assistance requests and resource distribution during natural disasters (e.g., floods, earthquakes). The system enables affected citizens to request essential supplies (e.g., food, water, medicine) or offer donations. Volunteers and civil protection vehicles are responsible for transporting supplies between citizens and a central base warehouse.

The platform includes three user roles:

    Administrator (Base Manager): Manages warehouse inventory, monitors requests/offers on a map, assigns tasks to rescuers, and generates notices for urgent needs.

    Rescuer (Volunteer/Vehicle Operator): Picks up/delivers supplies, manages active tasks, and updates the system in real time.

    Citizen: Creates requests/offers, tracks status updates, and interacts with the platform via a mobile application.

The system features map-based tracking, real-time updates, and filters for task visibility. It ensures efficient distribution of resources in disaster-affected areas by connecting citizens in need, volunteers, and administrators.
